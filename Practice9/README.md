# Practice7 – Pygame Projects 🎮

This repository contains three mini-projects built using Pygame:

## 📂 Projects

### 🕒 Mickey's Clock
A digital-style clock using Mickey Mouse hands.

**Features:**
- Displays current system time (minutes and seconds)
- Animated clock hands
- Real-time updates every second

---

### 🎵 Music Player
An interactive music player controlled by keyboard.

**Controls:**
- P – Play
- S – Stop
- N – Next track
- B – Previous track
- Q – Quit

**Features:**
- Playlist support
- Displays current track name

---

### 🔴 Moving Ball Game
A simple interactive game with a moving ball.

**Features:**
- Move ball using arrow keys
- Fixed step movement (20 pixels)
- Boundary collision handling
